# Sahayogi Aama

Sahayogi Aama is a sophisticated web application designed to connect parents with reliable babysitters and nannies. This platform ensures secure, efficient, and trustworthy interactions, focusing on personal data protection and user safety.

## Overview

Sahayogi Aama provides a user-friendly interface for parents to find nannies and for nannies to find job opportunities. The system is designed with a strong focus on security, ensuring safe handling of personal data and interactions.

## Features

- **User Registration and Authentication:** Secure user registration and login with email verification.
- **Profile Management:** Detailed profiles for both parents and nannies.
- **Booking Management:** Easy booking system with calendar integration.
- **Add to Favourites:** Parents can add nannies to their favourites list.
- **Contact Form:** Secure contact form for queries and feedback.
- **Secure Transactions:** Secure online payments for services.
